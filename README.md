# しゅがけレーティング

Sugar Cage IP / タップ連打ハイパーインフレ・バカゲー。
単一 `index.html`（CSS・JS 内包）。

**プレイ**: https://ghbe2.github.io/sc_rating/

---

## これは何か

- **負けは存在しない。** どう押しても勝つ。手が止まった時点が最終成績
- バトル（押し合い）→ 決着カット（WIN/LOSE）→ リザルト（連勝・ゲージ・昇格）→ ボタンで次へ
- 砂糖の甘さ等級を登り、**糖蜜級に到達するとレートが解禁**。以降は無限にインフレする
- 最後に**偽の全国ランキング**が出る（どう頑張っても最下位付近）

## 階級ラダー

```
グラニュー級 3→2→1 → ザラメ級 3→2→1 → 氷砂糖級 3→2→1 → 金平糖級 3→2→1 → 糖蜜級
```

昇格はポイント制。**最初の2ティアは4pt、以降は5pt**。
1勝 = 1pt だが、**3連勝目からは連勝ボーナスで2倍**（余ったptは次ティアに繰り越し）。
糖蜜級到達は **30勝**。

## 数字の扱い

状態として持つのは**総勝利数（整数）だけ**。階級もレートもそこからの純粋関数で復元します。
巨大なレート実数は保持しないので、通常の数値型で ×2 を続けたときの `Infinity` 破綻が起きません。

- 〜49勝（糖蜜級到達後）: 厳密整数で桁ローリング
- 〜235勝: 日本語単位（万〜無量大数）
- それ以降: 指数表記へフォールバック（6桁連勝でも壊れない）

## アセットの追加

どちらも**置いた分だけ差し替わり、無いものは既定の挙動のまま**動きます。
