# images/ — キャラ立ち絵の置き場

ここに画像を置くと、ゲーム内のキャラ・オーバーレイが自動で差し替わります。
**置いていないものは CSS のプレースホルダのまま**動くので、1枚ずつ追加しても壊れません。

## ファイル名（固定）

| ファイル名 | 表情 | 出る場面 |
|---|---|---|
| `rako_normal.png`   | 真顔       | 押し合い（拮抗） |
| `rako_surprise.png` | 驚き       | ピンチ（押し込まれる） |
| `rako_happy.png`    | キラキラ   | 逆転・押し切り・WIN・リザルト・昇格 |
| `rako_bored.png`    | 頬杖       | シーズン終了 |
| `ou_normal.png`     | ニヤリ     | 押し合い（拮抗） |
| `ou_surprise.png`   | 余裕       | ピンチ |
| `ou_happy.png`      | 笑い       | 逆転・押し切り・WIN・リザルト・昇格 |
| `ou_bored.png`      | ウィンク   | シーズン終了 |

## 仕様

- **形式**: PNG（背景透過）
- **縦横比**: 3:4 前後のバストアップ。画面右下に接地して表示されます
- **表示サイズ**: 幅 `min(34vw, 180px)`（バトル中）／ `min(22vw, 104px)`（リザルト等）
  → 実寸は **横 360px 前後**あれば足ります（Retina 考慮で 2倍の 720px 推奨）
- **重要**: 下端が切れる前提の構図にしてください（画面下辺に接地します）

ファイル名を変えたい場合は `index.html` の `CONFIG.chara.images` を書き換えてください。
