# images/ — キャラ立ち絵の置き場

ここに画像を置くと、ゲーム内のキャラ・オーバーレイが自動で差し替わります。
**置いていないものは CSS のプレースホルダのまま**動くので、1枚ずつ追加しても壊れません。

---

## 1. ファイル名（固定）

| ファイル名 | 表情 | 出る場面 |
|---|---|---|
| `rako_normal.png`   | 真顔       | 押し合い（拮抗） |
| `rako_surprise.png` | 驚き・口開け | ピンチ（押し込まれる／画面が赤くなる） |
| `rako_happy.png`    | キラキラ   | 逆転・押し切り・WIN・リザルト・昇格 |
| `rako_bored.png`    | 頬杖・退屈 | シーズン終了 |
| `ou_normal.png`     | ニヤリ     | 押し合い（拮抗） |
| `ou_surprise.png`   | 余裕の微笑み | ピンチ |
| `ou_happy.png`      | 笑い       | 逆転・押し切り・WIN・リザルト・昇格 |
| `ou_bored.png`      | ウィンク   | シーズン終了 |

> **オウの `surprise` に注意**。ピンチでも動じないキャラなので、驚き顔ではなく
> 「手を胸に当てた余裕の微笑み」を割り当ててください。

ファイル名を変えたい場合は `index.html` の `CONFIG.chara.images` を書き換えてください。

## 2. サイズ・解像度

### 結論

| 項目 | 指定 |
|---|---|
| **キャンバス** | **720 × 960 px**（縦横比 **3:4** 固定） |
| **最低ライン** | 540 × 720 px（これ未満は高精細端末でぼやける） |
| **形式** | **PNG-24 + アルファチャンネル**（背景完全透過） |
| **1枚あたり** | 150KB 以下（TinyPNG 等で圧縮） |
| **8枚合計** | 1.2MB 以下 |

### 根拠

ゲーム内の表示幅は CSS で以下のように決まっています（実測値）。

| 端末幅 | バトル中 | リザルト等（mini） |
|---|---|---|
| 320px | 109 × 145 px | 70 × 93 px |
| 375px（iPhone SE / 13 mini） | 128 × 171 px | 83 × 111 px |
| 390px（iPhone 14/15/16） | 133 × 177 px | 86 × 115 px |
| 430px（Pro Max） | 146 × 195 px | 95 × 127 px |
| 530px 以上 | **180 × 240 px（上限）** | 104 × 139 px |

**CSS 上の最大幅は 180px** です。最近のスマホは DPR（画素密度）が 3 なので
`180 × 3 = 540px`、DPR 4 の端末まで見込んで **`180 × 4 = 720px`** を推奨値としています。

### 縦横比は 3:4 で固定されています

コード側で `aspect-ratio: 3/4` を掛けてあるので、**比率の違う画像を入れても
レイアウトは崩れません**。ただし比率がずれた分は余白になって小さく表示されます
（例: サンプルシートの各コマは 4:3 の横長なので、**そのまま切り出すと縦に縮んで表示されます**）。
必ず **3:4 の縦長にトリミング**してください。

**8枚はすべて同じピクセルサイズに揃えてください。** 表情を切り替えたときに
顔の位置がズレると、瞬きのように見えて気になります。

## 3. 構図の指定

```
┌─────────────┐ ← キャンバス上端
│   ↑ 透明余白 5% 程度        │
│                              │
│      顔（ここが主役）        │  ← 128px 幅で読める大きさに。
│                              │     細かい描き込みは潰れます
│   ┌──────────┐   │
│   │   胸〜肩             │   │
└───┴──────────┴───┘ ← 画面の下辺に接地する
  ↑ 左右に 5% 程度の透明余白      ↑ 下端に透明余白を作らないこと
```

- **下端に透明余白を作らないでください。** 画像の下辺がそのまま画面の下辺に接地します。
  下に余白があると、キャラが宙に浮いて見えます
- **左右には 5% 程度の透明余白**を。画像の左辺が画面の左端に接するので、
  シルエットが端で切れて見えるのを防ぎます
- **顔を大きめに。** 実表示は 128px 幅（iPhone 標準）です。サンプルの引き気味の構図より、
  もう一段寄せた方が表情が伝わります
- 表情差分のあいだで**顔の位置・大きさを動かさない**こと

---

## 4. 確認方法

8枚を置いたら、ブラウザで `index.html` を開いてキャラを選び、バトルを1戦してください。
以下の順で表情が切り替われば正常です。

```
押し合い(normal) → ピンチ(surprise) → 逆転(happy) → 押し切り(happy)
  → WIN(happy) → リザルト(happy) → ［手を止める］→ 最終成績(bored)
```

1枚でも読み込みに失敗すると、その表情だけプレースホルダに戻ります（他は正常に動きます）。
ファイル名の綴りを確認してください。
